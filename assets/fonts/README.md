# Fontes da interface

As duas famílias de pixel art saíram do Google Fonts e moram aqui, em woff2
com as fatias latina e latina-estendida. O site não faz pedido de fonte para
fora: o visual não depende da rede nem troca de fonte no meio do carregamento.

- **Press Start 2P**, Copyright 2012 The Press Start 2P Project Authors.
- **Silkscreen**, Copyright 2001 The Silkscreen Project Authors.

Ambas usam a SIL Open Font License 1.1; o texto da licença está em `OFL.txt`.
Originais: <https://github.com/google/fonts/tree/main/ofl/pressstart2p> e
<https://github.com/google/fonts/tree/main/ofl/silkscreen>.
